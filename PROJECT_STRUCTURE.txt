╔══════════════════════════════════════════════════════════════════════════════╗
║                       API ENDPOINTS SUMMARY                                  ║
╚══════════════════════════════════════════════════════════════════════════════╝

Dashboard APIs:
  GET  /api/dashboard/stats           - Get dashboard statistics
  GET  /api/dashboard/recent-activity - Get recent activity

Employee APIs:
  GET  /employees/api/list            - List all employees (with filters)
  GET  /employees/api/<id>            - Get employee details
  POST /employees/api/create          - Create new employee
  PUT  /employees/api/<id>/update     - Update employee
  DEL  /employees/api/<id>/delete     - Delete employee
  GET  /employees/api/filters         - Get filter options

Analytics APIs:
  GET  /analytics/api/performance/overview - Performance metrics
  GET  /analytics/api/attendance/summary   - Attendance data
  GET  /analytics/api/trends              - Trend data

Payment APIs:
  GET  /payments/api/list             - List all payments (with filters)
  POST /payments/api/create           - Create payment record
  PUT  /payments/api/<id>/update      - Update payment
  GET  /payments/api/summary          - Payment summary stats
  GET  /payments/api/employee/<id>    - Employee payment history

Report APIs:
  GET  /reports/api/generate/employee-roster      - Generate roster CSV
  GET  /reports/api/generate/performance-report   - Generate performance CSV
  GET  /reports/api/generate/payment-report       - Generate payment CSV
  GET  /reports/api/generate/supervisor-report    - Generate supervisor CSV

╔══════════════════════════════════════════════════════════════════════════════╗
║                         QUICK START GUIDE                                    ║
╚══════════════════════════════════════════════════════════════════════════════╝

For Windows Users (Easiest):
  1. Double-click: start.bat
  2. Wait for setup (first time only)
  3. Browser opens to: http://localhost:5000
  4. Done! Start tracking employees! 🎉

Manual Method:
  1. Open PowerShell in this folder
  2. Run: python -m venv venv
  3. Run: .\venv\Scripts\activate
  4. Run: pip install -r requirements.txt
  5. Run: python scripts\import_sample_data.py
  6. Run: python run.py
  7. Open browser: http://localhost:5000

Stopping the Server:
  • Press CTRL+C in the terminal window
